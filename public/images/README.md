# Images

Naming convention (SEO-critical):
  articles/NN-slug-descriptor.jpg      e.g. articles/09-boiled-water-before-after.jpg

Rules:
- Original photos only (your pans, your kitchen). Stock photos kill E-E-A-T.
- 3+ images per article: hero (1200x800+), process, result.
- Compress to < 200KB each before uploading (squoosh.app or macOS Preview export).
- Alt text = describe what's shown + natural long-tail variant. Never the primary keyword verbatim.
- Add files via GitHub web UI: public/images/articles/  (create the folder by uploading a file into it)
